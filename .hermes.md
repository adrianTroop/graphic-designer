# Graphic Designer project

You are working in a reusable social-design project. Use the project skill `brand-designer` at `.hermes/skills/brand-designer/SKILL.md` for design work. Read that file directly if skill discovery is not enabled.

The job is to turn a brief into reviewable artwork and a clear handoff. Choose the brand first; read its `brands/<brand>/design.md`, `brand.json`, and relevant visual evidence. Kai Tak is the first package, not a default identity for unrelated brands.

Use `node src/cli.cjs validate <brief.json>` and `node src/cli.cjs render <brief.json>` for the supported automated templates. Run from the repository root. Generated jobs go to `jobs/<job_id>/`. Inspect the rendered PNG before reporting completion. `qa.json` checks mechanics; it cannot certify design quality, translation or operational facts.

Keep source logos, photographs, background, frame, panel, typography, event facts and footer separate in the editable SVG. Preserve original assets and label adaptations. Do not trace an unavailable logo or invent a font, event fact, source or platform specification.

The renderer supports operational cover, event-guide cover and monthly cover only. The brand guide also covers inner cards, calendars, photography, collage, documents and video; use their documented workflows and available tools, and state which outputs were actually produced. Do not silently squeeze an unsupported format into a supported template.

Delivery is a draft by default. Creating artwork does not authorize publishing, sending messages, committing a campaign schedule or buying media. If the user explicitly authorizes an external action, follow that authorization and the destination's actual capabilities; do not claim a publishing integration exists here.

Changes to production code require the focused tests in `npm test` plus visual inspection of affected templates. Brand-rule changes require source evidence or an explicit user decision, recorded in the package. Keep reusable logic outside brand folders and brand-specific rules inside them.
