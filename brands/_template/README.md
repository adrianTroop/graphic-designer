# New brand scaffold

Create a working package with:

```bash
node src/cli.cjs init-brand my-brand --name "My Brand"
```

The command writes `brand.json`, `design.md`, an empty asset manifest, an example brief and the three workspace-settings source files. It refuses to overwrite an existing package. The neutral starting colours, font, templates and workspace summaries are provisional and must be adapted to the brand.

For paste-ready Design guide, Image style, Brand colours and Fonts fields, follow [workspace settings](../../docs/workspace-brand-settings.md). The full `design.md` may include pictures; `workspace-design.md` is a separate text summary.

Use [brand onboarding](../../docs/brand-onboarding.md), the [template contract](../../docs/template-contract.md) and the [brief contract](../../docs/brief-contract.md). No logo, event field, industry or language pair is required. Add assets only from appropriate sources and record their provenance.
